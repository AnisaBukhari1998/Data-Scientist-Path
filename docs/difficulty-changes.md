# Difficulty level changes

Only the level field changed in `src/data/roadmap.js`; no items were added, removed or reordered.

How levels are assigned:

- **Beginner**: no prior knowledge needed.
- **Intermediate**: assumes basic Python and basic statistics or maths.
- **Advanced**: needs solid ML or maths first (graduate courses, research-level books).
